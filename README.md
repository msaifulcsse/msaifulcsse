### 🔹 Biznify — Enterprise ERP Platform
**Role:** Backend / Full-Stack Developer · **Stack:** ASP.NET Core 5 · MySQL · Angular · Microservices · REST APIs
Modular ERP covering CRM, accounting, inventory, eCommerce and manufacturing. Designed and implemented core microservice REST APIs and service boundaries.

### 🔹 RAMS-APP — Risk Assessment & Safety Management (UK Client)
**Role:** Software Engineer · **Stack:** ASP.NET Core · MSSQL · Azure Blob Storage · Stripe · KendoUI

**Role:** Full-Stack Developer · **Stack:** Supabase · PostgreSQL · ASP.NET Core · Cloudflare R2 · Google SSO
Finance/business SaaS built on Supabase (PostgreSQL) covering transactions, budgets and reports. Designed the database schema and implemented core workflows end-to-end, with Google SSO and Cloudflare R2/Turnstile integration.

### 🔹 Tasker24 — Multi-Sided Service Marketplace
**Role:** Full-Stack Developer · **Stack:** Next.js · React · Tailwind CSS · Neon (PostgreSQL)
Modern service marketplace with role-based dashboards. Built frontend features and API integration against a Neon-backed PostgreSQL database.

### 🔹 StockDigital — Business Management SaaS
**Role:** Full-Stack Developer · **Stack:** ASP.NET Core · Neon (PostgreSQL) · React · Docker · CI/CD
Modular business-management platform with separate Web/API services. Designed the database schema and Dockerized CI/CD deployment pipeline.

### 🔹 MetroCRMPro — Omnichannel CRM Platform
**Role:** Full-Stack Developer · **Stack:** ASP.NET Core 8 · MySQL · MVC · Mobile Integration
Multi-industry CRM with onion architecture and cross-platform mobile integration. Led architecture design and backend development.

### 🔹 DistribuPro — Multi-Tenant Distribution SaaS
**Role:** Full-Stack Developer · **Stack:** ASP.NET Core 8 · MySQL · React · REST API · Multi-Tenancy
FMCG distribution SaaS with a clean REST API and React frontend. Designed the multi-tenant schema and API layer.

### 🔹 ServiceNin — Service Sales Automation Platform
**Role:** Full-Stack Developer · **Stack:** ASP.NET Core 5 · MSSQL · React · REST API · Mobile
Service-sales automation platform with customer, service and technician workflows, plus a companion mobile app.
